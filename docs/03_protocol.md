# XRK 局域网远程控制软件 - 通信协议设计文档

## 1. 协议概述

XRK使用自定义二进制协议进行通信，支持TCP和UDP两种传输方式。

## 2. 消息格式

### 2.1 消息头 (固定24字节)

```
+--------+--------+--------+--------+--------+--------+
| Magic  |Version |  Type  | Length  |   Timestamp      |
| 4字节  | 4字节  | 4字节  | 4字节  |     8字节        |
+--------+--------+--------+--------+--------+--------+
|              Session ID (变长字符串)                   |
+------------------------------------------------------+
```

- **Magic**: 0x58524B00 ("XRK\0") - 用于消息同步
- **Version**: 协议版本号，当前为1
- **Type**: 消息类型枚举
- **Length**: 负载数据长度（不含头部）
- **Timestamp**: 毫秒级时间戳
- **Session ID**: 会话标识（变长UTF-8字符串）

### 2.2 消息体 (变长)

根据消息类型不同，负载格式各异。

### 2.3 校验和 (4字节)

CRC32校验，覆盖头部+负载。

## 3. 消息类型

### 3.1 设备发现 (UDP)

#### DEVICE_DISCOVER_REQ (0)
```
无负载
```

#### DEVICE_DISCOVER_RESP (1)
```
+------------+--------------+-----------+--------+---------+
| Device ID  | Device Name  | IP Address| Port   | Version |
| (变长)     | (变长)       | (变长)    | 2字节  | (变长)  |
+------------+--------------+-----------+--------+---------+
```

### 3.2 连接管理 (TCP)

#### CONNECT_REQ (10)
```
+------------+--------------+
| Device ID  | Session Token|
| (变长)     | (变长)       |
+------------+--------------+
```

#### CONNECT_RESP (11)
```
+----------+--------------+
| Success  | Error Message|
| 1字节    | (变长)       |
+----------+--------------+
```

#### DISCONNECT_REQ (12)
```
无负载
```

### 3.3 远程桌面 (TCP)

#### SCREEN_FRAME (20)
```
+----------+--------+--------+--------+----------+---------+
| Width    | Height | Format | Flags  | Timestamp| Frame   |
| 4字节    | 4字节  | 4字节  | 4字节  | 8字节    | (变长)  |
+----------+--------+--------+--------+----------+---------+
```

#### SCREEN_FRAME_ACK (21)
```
+----------+
| Frame ID |
| 8字节    |
+----------+
```

### 3.4 输入控制 (TCP)

#### MOUSE_EVENT (30)
```
+--------+--------+--------+----------+--------+
|   X    |   Y    | Action | Button   | Delta  |
| 4字节  | 4字节  | 4字节  | 4字节    | 4字节  |
+--------+--------+--------+----------+--------+
```

#### KEY_EVENT (31)
```
+----------+----------+------------+
| Key Code | Pressed  | Modifiers  |
| 4字节    | 1字节    | 4字节      |
+----------+----------+------------+
```

### 3.5 文件传输 (TCP)

#### FILE_REQ (40)
```
+----------+-----------+----------+----------+--------+
| File ID  | File Name | File Size| Offset   | IsUp   |
| (变长)   | (变长)    | 8字节    | 8字节    | 1字节  |
+----------+-----------+----------+----------+--------+
```

#### FILE_DATA (41)
```
+----------+--------+----------+---------+
| File ID  | Offset | Length   | Data    |
| (变长)   | 8字节  | 4字节    | (变长)  |
+----------+--------+----------+---------+
```

#### FILE_ACK (42)
```
+----------+----------+--------+
| File ID  | Offset   | Success|
| (变长)   | 8字节    | 1字节  |
+----------+----------+--------+
```

### 3.6 心跳 (TCP)

#### HEARTBEAT (100)
```
无负载
```

#### HEARTBEAT_RESP (101)
```
无负载
```

## 4. 连接流程

```
Client                              Server
  |                                    |
  |--- DEVICE_DISCOVER_REQ (UDP) ---->|
  |                                    |
  |<-- DEVICE_DISCOVER_RESP (UDP) ----|
  |                                    |
  |--- CONNECT_REQ (TCP) ------------>|
  |                                    |
  |<-- CONNECT_RESP (TCP) ------------|
  |                                    |
  |<========= 数据交换 ===============>|
  |                                    |
  |--- DISCONNECT_REQ (TCP) --------->|
  |                                    |
```

## 5. 错误处理

- 校验和失败：丢弃消息
- 消息格式错误：断开连接
- 超时未响应：重试3次后断开
